# BrightBoard AI Tutor

Free, open-source-style starter for a tablet-first AI whiteboard tutor. See [SETUP.md](SETUP.md) for installation and the honest feature/limitation list.

```bash
npm install
npm run dev
npm run server
```

The frontend runs on port 5173 and the optional AI gateway on port 8787. Configure a real Ollama model or compatible server-side provider before expecting generated tutoring.
